# Local invitation fonts

Downloaded from the official Google Fonts repository on 19 September 2026:

- [Great Vibes regular](https://github.com/google/fonts/tree/main/ofl/greatvibes): `GreatVibes-Regular.ttf`. License: `GreatVibes-OFL.txt`.
- [Cormorant Garamond variable](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond): `CormorantGaramond-Variable.ttf`, weight axis 300–700. License: `CormorantGaramond-OFL.txt`.

The `.woff` files were losslessly repackaged locally from these TTF files using FontTools, without changing the outlines or removing glyphs. Use WOFF with `font-display: swap` in the website to reduce download size. The original TTF files are retained as sources. These local assets do not contact Google when a guest opens the invitation.
